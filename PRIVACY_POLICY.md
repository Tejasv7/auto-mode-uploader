# Privacy Policy & Terms of Service

## Auto-Mode Uploader

This application is a personal automation tool for managing and uploading video shorts to YouTube via the YouTube Data API v3.

### Data Collection & Usage
- **Credentials**: Google OAuth tokens and API keys are stored securely in GitHub Secrets and local environment files. They are used strictly to authenticate API requests for video uploads.
- **Data Sharing**: No user data, video data, or credentials are sold, shared, or transferred to any third party.
- **YouTube API**: The app adheres to the [YouTube Terms of Service](https://www.youtube.com/t/terms) and [Google Privacy Policy](https://policies.google.com/privacy).
